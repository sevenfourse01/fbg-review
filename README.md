# FBG demo surface — review build

Static review build of the Forecast / Build / Grow demo surface, for internal
review only. The prior pack in this build is synthetic; the app therefore
runs on the console surface and says so in the banner at the top of the page
("This build must not be shown to a prospect"). Every figure is real engine
output; the priors behind it are not fitted to real engagements. The footer
states the pack positively on every run: version, hash prefix, and whether
it is synthetic or fitted.

`fbg-demo-run.webm` is a recorded end-to-end run of the same build.
